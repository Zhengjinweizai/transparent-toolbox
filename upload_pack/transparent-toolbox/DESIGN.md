# Transparent Toolbox v2 产品设计

> 调研对象：iStat Menus 7 / Stats(exelban) / One Switch / Maccy / Paste / Raycast / Dropover
> 设计依据：Apple HIG Widgets & Materials（glanceable、语义色、材质层级、内边距≈外边距50–75%）

## 一、调研结论

| 软件 | 值得借鉴 | 我们怎么做 |
|---|---|---|
| iStat Menus / Stats | 数据**图表化**（曲线+数字双呈现）、磁盘/CPU/内存/网络全覆盖 | SysInfo v2：Sparkline 历史曲线 + 磁盘 + 开机时长 |
| One Switch | 一键开关集合（暗色模式/桌面图标/屏保…） | 新部件「快捷开关」 |
| Maccy / Paste | 剪贴板**搜索**、时间戳、置顶 | 剪贴板 v2 |
| Raycast | 启动器+计算器融合 | 已有（算式即算），保留 |
| Dropover | 文件搁架 | 跳过（复杂度高、收益低） |

## 二、UI 设计系统 v2

1. **排版层级**：时钟 34 semibold；卡片标题 11 medium（icon + 圆角底衬）；正文 12；辅助 10.5 次要色
2. **卡片**：圆角 14，内边距 12/14，背景 labelColor 6%，描边 separator 40%；**每卡片可独立折叠**（右侧 chevron，状态持久化）
3. **间距**：卡片间 10、头部-内容 8、面板 gutter 14（内≈外的 60%）
4. **色彩**：accent / success / warning / danger 语义色；全部基于系统语义色适配深浅色
5. **组件**：MiniBar→统一 Gauge；新增 Sparkline（60 点历史曲线）；环形进度 RingProgress；空状态（图标+文案）
6. **交互**：按钮 hover 高亮、卡片折叠动画、头部可整体拖动窗口

## 三、功能路线（论证：影响面×性价比）

- **P0 系统信息 v2**：CPU/内存/网速三条 Sparkline 历史、磁盘用量条、开机时长 —— iStat 类最核心卖点
- **P0 剪贴板 v2**：搜索过滤、相对时间戳、置顶 3 条、上限 50 —— Maccy 核心体验
- **P0 番茄钟 v2**：环形进度、今日完成轮数（按日持久化）、阶段自动切换+提示音
- **P1 快捷开关**（新部件）：深浅色切换、启动屏保、隐藏/显示桌面图标、清倒废纸篓 —— One Switch 精华
- **P1 时钟 v2**：本地时间 + 纽约/伦敦/东京世界时钟一行
- **P1 倒计时**：结束提示音已可，加最后 10s 面板标题闪动（轻量）
- **P2（视时间）**：计算器键盘输入、主题色切换

## 四、验收标准

1. 编译零错误零警告；verify.sh 全过
2. 单元测试（MathParser + 新增 Sparkline 数据缓冲）通过
3. 运行实测：面板渲染完整、14+1 部件、滚动流畅、深浅色切换正常
4. 状态持久化向前兼容（v1 state.json 可读）

## 五、v2.5 Bento 栅格改版（2026-10-28）

调研 Bento Grid 趋势（源自 Apple 官网/iOS 小组件）：模块化卡片、大小混排、大圆角、留白呼吸感、hover 微交互。

- 面板 320→450px，**双列瀑布流**：半卡自动进较矮列（FlippedView + 手工 masonry），整卡横跨两列
- 跨整列：时钟、剪贴板、密码生成、取色器、启动器；其余半卡紧凑化（待办输入 150、倒计时条 180）
- 配对节奏：时钟通栏 → (系统信息|番茄钟) → (倒计时|秒表) → (待办|便签) → (计算器|二维码) → (快捷开关|截图贴图) → 剪贴板/密码/取色/启动器通栏
- 滚轮滚动浏览全部卡片；卡片折叠/展开实时重排
